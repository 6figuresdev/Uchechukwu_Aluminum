# Uchechukwu Aluminum

Website for Uchechukwu Aluminum: aluminum and PVC windows, office partitions, demarcation and doors.

Plain HTML, CSS and JavaScript. No build step.

## Run it
Open `index.html` in a browser, or run `npx serve` in this folder.

## Update things
- **Phone and WhatsApp:** edit `CONFIG` at the top of `js/main.js`.
- **Products and photos:** edit the `ITEMS` list in `js/main.js`. Put photos in `images/` and set `img: 'images/your-photo.jpg'`. Cards with no `img` show a drawing.
- **Address and hours:** edit the Contact section in `index.html`.
- **Colors and fonts:** edit the variables at the top of `css/style.css`.

## Deploy
Static site. Import the repo on Vercel or Netlify with no build command, or turn on GitHub Pages for the `main` branch.
